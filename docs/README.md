# Carpeta docs

Aquí se deben incluir:

1. **Seguimiento en papel del AVL** (foto o escaneo): inserción de la secuencia
   50, 30, 70, 20, 40, 35, 10, 5, 80, 90, 85, dibujando el árbol después de
   cada rotación (requerido para la sustentación, Fase 3).

2. **Diagrama de clases del sistema**: puede ser un dibujo hecho a mano o un
   archivo generado que muestre los paquetes `estructuras`, `modelo`, `servicios`
   y `util`, con sus principales clases y relaciones de dependencia.

Nota: ambos elementos son entregables de la Fase 3 y Fase 4 y se revisan en la
sustentación.
